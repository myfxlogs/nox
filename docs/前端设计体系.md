## 2. 设计原则（判据级，非审美）

1. **第一眼层级**：每页按「业主第一眼问题」定段序——**行动（该我做的）→ 裁决（系统判的可抓/观望/坑）→ 健康（系统活着+数据新鲜）→ 信号（告警/触发）→ 下钻（全量明细折叠）**。段序即判据，留 D# 注释。
2. **状态语义色不配字**：徽标=色点+文字，色永不独立载义（arb 纪律）；`unqualified`=「观察中」非终判样式。
3. **显式空态**：段永不消失——「引擎评估中·暂无候选」「数据不足不产卡」类占位，诚实标注数据边界。
4. **逐格新鲜度**：FreshDot 式源健康点（live/stale/down+时点 title），数据陈旧看得见——复用既有 `sourceHealth` stream case。
5. **诚实标注**：展示口径注来源/用途（「不喂策略不落库」「快照每拍刷新」），缺数据显缺不显 0。
6. **流驱刷新**：页面一律 `onCase` 订阅+拖尾重取（overview.tsx 2s 范式），**禁 setInterval 轮询**（D-004）。

## 3. CSS token 化（app.css → styles/ 模块）

移植 arb 件结构（按需裁剪，不逐行搬）：

```
styles/00-base.css        设计 token（page/surface/ink/line/accent/状态色变量）+ reset
styles/01-layout.css      shell/top nav/grid/cards
styles/02-components.css  table/chip/collapse/stat/fresh-dot/empty
styles/03-pages.css       页面特型（investor 抽屉/graduation 表等）
styles/04-theme-dark.css  暗色变量覆盖（prefers-color-scheme + data-theme 双径）
```

- 状态色固定不随主题；文本/表面双主题，暗色=同色阶步进（arb 原案）。
- **纯 CSS 不变**（契约钉死禁 Tailwind/框架件）；零新依赖。

## 5. 页面层级判据（第一眼序规范）

各页按 §2.1 判据重排，示例=投资人页（门面先行）：

```
① 请求箱（该我行动——资本/凭据请求）        ← 已置顶，保持
② 毕业授权（该我裁决——pending 卡+dry_run）  ← 已默认展开，保持
③ 观察中（系统在看什么+差多少）            ← 在施票 @1bc019259 并入
④ 持仓·策略格（在跑的钱）                  ← pos-grid 补正版并入
⑤ 账本（日收益/DCI 收益轨/io）             ← 折叠下钻
⑥ 明细下钻（财务快照/尘币/全量历史）        ← 默认折叠
```

其余页同法重排（overview 已合规、positions/accounts/risk/watch/capital 逐页过一遍段序+订阅矩阵）。

## 8. 禁线

- 禁轮询/setInterval（D-004）；禁前端重算业务判据（判据单源=后端）。
- 禁新依赖/Tailwind/UI 框架（契约：纯 CSS）；禁动 RPC 契约与 proto（透出字段缺的走单独后端票）。
- 禁「美观重构」名义改文案语义——投资人可见文案三要素/中文映射惯例保持。
- 每片独立 commit+机检；巨石拆分不混逻辑改动（纯移位）。
