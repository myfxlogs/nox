## 0. 对原稿的裁定

## 1. 瓶颈重判：不是验证慢，是终态零成交

原稿把 paper→毕业 5-21 天列为🔴瓶颈。产线实数（10-19 实拍）：

| 指标 | 实值 |
|---|---|
| fin_opp_hypothesis | 74（28 proposed / 1 approved / 2 trialing） |
| xasset_allow_combos | 19，armed 3 |
| **真金仓** | **0（全生命周期）** |
| **执行日志** | **0** |
| 决策账本 decision_outcomes 真金样本 | **0** |
| 唯一真金动作 | earn 申购 3 笔（$1000@0.10%） |

**真瓶颈=学习环在末端断粮**：零成交→零 outcome→Kelly/复盘/淘汰判据全体在等不存在的数据。发现段产出>消费段消化——再提速验证（①）是在给一个末端堵死的漏斗加速进料。

**修正原则**：迭代速度的度量不该是「参数验证周期」，该是**单位风险产出的学习信号量**。一笔 $200 真金试单产生的执行/成本/归因数据，胜过纸面一个月的模型值。

## 3. 三个增补件（原稿所无）

### A. 微额试单轨（micro-trial tier）——paper 与 armed 之间加一层

**问题**：carry 族策略真正要学的不是「参数哪个好」，是**实测成本模型**——fee、滑点、划转时滞、funding 实收 vs 预期、venue 断供率。这些**不存在于行情数据里**，回测天然看不见，纸面仓也碰不到。纸面 5 天学到的是模型对模型的自洽，试单 3 天学到的是模型对世界的偏差。

**机制基础已存在**：D-624 s2_trial_notional_usd=$200 已是正式闸——本件只是把它从「单点试授权」泛化为「毕业前必经的量产品阶级」：

```
paper（参数确认，可提速到 ~3 天）
  → trial（$200 微额真金，1-3 天，每 combo 一次）   ← 新层
  → armed（正式额度）
```

- trial 仓的每笔 fill/settle 实收全部落 `cost_model` 事实表（见 C）
- trial 失败的组合回 paper 或退——**淘汰证据来自真金实测而非纸面推断**
- 风控：$200/次、并发 ≤2、trial 累计敞口另设硬帽——灰尘级风险，毕业级证据

**对 ≥8% 的贡献**：学习环闭合提前到「周」级；同时把 kill 扳机从「事后亏损」提前到「试单即证伪」。

### B. 数据覆盖账本（coverage ledger）——① 的前置而非附属

**问题**（今日实证）：`BZUSDT-BRENT×3001157` 簿 10-10~10-18 饥饿断粮（~7 行/日 vs 10-09 的 169 行）→noise NULL→补锚径结构收口不了→锚死告警持续 9 天。**没有任何哨兵报「这对数据不够学」**——系统自盯告警族，不自盯数据充分性。

**落法**：能力账本扩一维——每 (pair, venue) 记覆盖率指标：

| 指标 | 阈值语义 |
|---|---|
| 行数/24h | <12=饥饿（noise 阈同源） |
| 最新行龄 | >采集周期×3=断供 |
| 会话对齐 | 应开市窗内零行=覆盖缺 |
| noise/floor 非空率 | 噪声断供=衍生轴缺 |

用途两吃：**线上**=「数据不可判」显式告警（别让系统对着饥饿簿装正常）；**回测**=回放窗准入闸（C 件消费）。

### C. 成本模型实测化（cost-model feedback）——回测的自我修正机制

回测对 carry 族的系统性高估根源=成本在行情数据外（划转/费用/时滞/断供）。本件让系统**自校准**：

- 每次 trial/armed fill 记实收：手续费实值、fill vs 簿锚 drift、划转耗时、funding 实收 vs 预期差
- 落 `cost_model` 事实表（venue×结构×时段维度）
- 回测引擎参数**优先读实测成本**，无实测才用模型默认并标注「假设口径」
- 时间维度越滚越准——回测可信度随真金样本增长

**这条是原稿最大的结构性遗漏**：没有它，回测只是更快地产生更自信的错参数。

## 5. 对原稿两个提法的直接纠偏

1. **「迭代速度×5」口径**：成立前提是参数选择是瓶颈。实际瓶颈排序：**执行末米未证（堵点在权限/信号，今天刚解一半）→ 真金样本为零 → 参数迭代速度**。① 照建但叙事诚实——它加速挑参数，不加速赚钱。
2. **「detector/gate/evaluator 是纯函数」**：待验证项非事实——判定链消费 `LatestFactsByKind`（非时态）/venue 快照/池状态，回放要 as-of 谓词+快照时态化，工期比 ~2-3 天乐观口径要多估一档。

## 6. 风险与反证锚

- **试单轨风险**：$200×并发2=灰尘级；反证锚=若 trial 首月成本实收系统性超模型值 >X%（阈值随数据定），说明成本模型整体失真→回表。
- **覆盖账本风险**：零——纯读面件，不产动作。
- **P0 依赖**：gate 权限已开（业主 10-19 实拍）——armed#19 信号再触发即首单候选；combo#20 试单授权仍走 D-624 另闸，本件不替它开门，只把它泛化成产线。
