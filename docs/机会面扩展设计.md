## 3. 撬板一：模板枚举×能力账匹配引擎（D-184 钦定，缺件）

现状痛点：假设靠**人提**（假设#5/#505 皆业主/席位手工），枚举不穷尽、能力账（docs/能力账/）与模板表**无程序性连接**。

引擎 v0（纯发现工具，零交易代码）：
```
fin_opp_template（10 张）× 能力账（venue/账户/符号/费率/杠杆/限额面）
  → 可行性矩阵：每模板×每 venue 组合 = feasible / blocked(缺何条件) / missing(能力账无据)
  → 输出双流：①feasible 未立项面 → 自动产 hypothesis 草案入册（人审后进管线）
             ②blocked 面 → fin_condition_gap 候选（缺条件显式化=业主请求箱，D-184 强制义务）
```
- 落点：cmd/core 加枚举任务（或 universe-radar 同轴挂载），输出落 `docs/报告/枚举矩阵/`（运行时件面）+feasible 清单 STATE 行
- **禁线**：引擎只产提案不产交易；能力账无据=missing 如实（禁编造）；零新定时器轴外的业务数据（挂既有 radar 轴）
