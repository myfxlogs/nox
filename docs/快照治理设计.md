## 0. 语义边界（「快照」禁什么、留什么）

| 形态 | 定性 | 处置 |
|---|---|---|
| 周期性状态摄取（timer 驱动 REST 拉账户/余额/权益写状态表，读时当现值） | **快照（禁域）** | 退役 |
| 判定/执行/风控/淘汰/装配/评估径读陈值（表列/冻结列/TTL 缓存/轮询产物） | **快照消费（禁域）** | 换流或消费点实拉 |
| 提案时点冻结列（graduation/paper 快照列） | 档案 | 保留历史，禁作现值；现值=live 列+重校验（D-576） |
| 流事件持久化行（okx_event/binance_event/mt_frame src 行） | **事件落地≠快照**——流的持久化形态，D-544 权威源 | 保留；读径鲜度闸强制 |
| 事件锚定拉取（boot 首读/断流重连自愈/kick 定向回读/消费点拉取/手动 Refresh） | 合法（D-523 架构） | 保留 |
| 批处理/会计日切（NAV 日切/swap 计提/日报/备份 cron） | 非判定径批处理 | 分类豁免，禁喂实时判定 |

判据一句话：**读到的值必须可追溯到「产生它的那次流事件或那次拉取」，且那次事件/拉取的时点满足消费面的鲜度要求**。
