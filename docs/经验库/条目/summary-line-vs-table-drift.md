# 摘要行与明细表参数漂移：复审必须复算结论行

## 症状

D-171 立项调查报告（GLM5.2 High 产出）：Q4 表格与费率证据（E3）一致用 25 bps 双腿成本，但同节**结论行**写「持有 20 天净收益 13.4 bps（日均 0.67 bps/日）Sharpen 1.4」——反推自 20 bps 成本（近似记忆值）。两者并存于同一节，未自洽。且向业主的裁决摘要把**毛** carry（1.671 bps/日）当**净**收益与 SWAPARB 0.494 对比——口径升格发生在摘要层，表格层从未出错。

## 根因

- 弱后端生成长文档时，表格按引用的证据参数逐格计算，结论行凭上下文记忆「重新心算」——参数取近似值（20 而非 25）且不回查。
- 摘要行倾向选「更强的表述」（毛→净不标注），表格保持忠实——数字美化和参数漂移都发生在摘要层。
- 复审者若只对拍「表格 vs 证据源」，摘要行的独立错误不可见。

## 通用解法

**复审复算顺序：结论行 → 表格 → 证据源，三层各自独立复算**，不假设同文档内部自洽。对交付给业主的裁决摘要，凡「净/毛、before/after、含/不含成本」的数字显式标注口径。委任弱后端产出判定文档时（预注册标准+证据标签制框架下），把「结论行独立复算」列入补审固定动作——本次即由该动作抓出（D-170/D-171 补审修正 1/2）。
