消费侧的时效守门与写速节流，按「想当然的节奏」设阈值而不实测写源，两类翻车同根：

1. **守门 vs 写源节奏**（D-591 R1）：funding_interval fact 守门 15min，唯一写源=日轮采集器（24h+boot）→部署即 ~95% 时段 fail-closed 误报刷屏。修=守门按写源节奏定标（近静态元数据 25h，动态数据 15min 不动）。
2. **节流 vs 值分布**（D-592→D-595）：「与 funding 同款值变去重节流」对慢变值天然生效（funding 1.74 行/s），对逐帧必变的 index 零抑制（55 行/s≈470 万行/天）——去重节流的效果由**值分布**决定，快变值必须显式 min-interval/心跳。

共同律：任何闸值/守门/节流上线前，先实测写源的**节奏（cadence）与值分布**两个维度；上线后第一小时拉实测复核（D-350 闸值定标教训的二维扩展）。证据：arb 2026-09-30 D-591 R1（gate 腿间歇误报）+D-595（facts +1.9GB/天）。
