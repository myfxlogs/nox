> 复制本文件到 `条目/<id>.md`，替换字段值。frontmatter 字段规则见设计 §4.2，正文六节见 §4.3。

```yaml
---
schema_version: 2          # 当前为 2（无 v1，不迁移）
id: <kebab-case-id>         # 全库唯一、稳定、ASCII 小写 kebab-case
kind: pitfall               # pitfall / strategy / invariant / ops
risk: high                  # critical / high / medium / low
status: observed            # observed / verified / disputed / retired
keywords: [关键词, 报错原文, 症状, 技术栈, venue, symbol, 工具名]
scope: [适用模块, 资产, venue, 环境, 版本]
summary: 一行短摘要，索引唯一来源，默认不超过 200 字符
first_seen: 2026-08-21      # 首次发现日期
last_verified: 2026-08-21   # 最近验证日期；动态事实需更新
skills: [KB维护, 事实核验]   # 关联 Skill 名称，可为空 []
evidence_refs:              # 统一证据引用字段（不同时维护 source_refs）
  - type: decision          # decision（D#）/ commit（短码）/ doc（file:line 或文档路径）/ review_signature / server_fact
    ref: D-0XX
  - type: commit
    ref: a1b2c3d
  - type: doc
    ref: internal/path/file.go:42
  - type: review_signature
    ref: review:summary:CROSS_VENUE
  - type: server_fact
    source: postgres         # postgres / rpc / mt4 / mt5 / cex
    query: SELECT ...        # 只读 SQL 或 RPC 名；禁含 DSN/凭据/token
    observed_at: 2026-08-21T12:00:00Z
    server_revision: ""      # 配置/版本，如有
    response_hash: ""        # 脱敏结果哈希
---
```

## 退役（status: retired）

条目失效即滚出，索引只载活条目。判据（满足其一即退，存疑不退）：
- **被取代**：新条目覆盖同主题（正文注明 supersedes 关系）。
- **系统已移除**：条目针对的代码路径/venue/工具已不存在。
- **已证伪**：反证条件触发（falsifies_when 命中）。
操作：`git mv 条目/<id>.md 归档/` + frontmatter `status: retired` → `arbkb gen` 重生成索引 → 同 commit。
检索：归档条目不进索引；`grep -r docs/经验库/` 仍可命中全文。
