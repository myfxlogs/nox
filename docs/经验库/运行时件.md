# 运行时件清单（不入 git）

deploy_sync `--files-from=git ls-files` 只推跟踪件——运行时写盘产物一旦入 git 会被本机旧版回刷
（2026-10-14 实证：待归纳.md/水位件 SG 写盘被回刷，alerts 水位化石 64904>max 289=永久零增量）。

| 文件 | 写者 | 语义 |
|---|---|---|
| `待归纳.md` | tools/digest（cron 06:10） | 当日未消解事件聚合覆写 |
| `待归纳-分析员.md` | cmd/core `AppendAnalystNote`（RPC「记一下」） | 分析员收件箱 append |
| `.digest_state` | tools/digest | 水位 `{"autotrade_logs_max_id":N,"alerts_max_id":N}`；库内 max(id) < 水位时 digest 自愈钳回 |
| `归档/待归纳-YYYY-MM*.md` | tools/digest 消解出口 | ✅ 行按月归档，幂等追加 |

仍入 git 的知识产物：`条目/*.md`（digest 追加重现行经 `-commit` 入库）、`索引.md`、`技能清单.md`
（noxkb gen 产物）、`归档/` 下非待归纳前缀的条目归档。
