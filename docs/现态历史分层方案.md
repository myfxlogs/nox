## 1. 病灶实证（SG 三通道 10-20 05:3xZ）

| 证据 | 值 | 通道 |
|---|---|---|
| pg CPU | **202.95%** 持续 ≥3.5h 不落底（03:56 死锁修后至今） | docker stats |

**机制**：`WHERE venue AND venue_type AND symbol ORDER BY ts DESC LIMIT 1` 在裸 `ts` 索引上=从最新行逆扫至首个命中；停喂/休市/低频符号须倒扫整日——每次都是全表级代价。锤击源=`pendingGateWatcher`（qbus **每帧**标脏→逐组合逐腿重估闸 4）+毕业风险+broker adapter 复合钟 miss 级。

**本质**（D-633）：「最新价」是**现态**，却从**时序归档表**逐次点查。一张表两种访问模式（时间分块归档 vs 键点查现态）互噬；索引只让互噬便宜，不消除。

## 4. 止血（P1 消化票——今日）

**复合索引** `ticks (venue, symbol, venue_type, ts DESC)`：
- 列序理由：三等值列任序皆可服务 `LatestTick`；`(venue,symbol)` 前缀服务 `LatestTickMid` 族（3.1 切完即无此需求，但索引窗期内仍有调用）与 3.2 回退；ts DESC 尾列=LIMIT 1 直取
- 表形态（SG 实拍）：生产 ticks=**TimescaleDB hypertable**（D-626 C 段；现单 chunk `_hyper_2_8_chunk` 10-15→10-22，7 天 chunk，**262 万行/322MB**——倒扫一个死符号=扫整 chunk，与 7.5s 单条吻合）；测试库=声明式月分区（`EnsureMonthPartition` 仅 fixtures 域）。两形态下父表 `CREATE INDEX IF NOT EXISTS ticks_key_ts_idx ON ticks (venue, symbol, venue_type, ts DESC)` **一条语句皆自动级联子表**——迁移文件单语句即可双库通过
- 锁窗：hypertable 与分区父表**均不支持 `CONCURRENTLY`**；普通 `CREATE INDEX` 持 SHARE 锁阻写（`TickSampler` 60s 节流写入会在锁窗内积压/超时）。322MB 单 chunk 建索引量级=数十秒（200% CPU 下放大）——**可接受的一次性写停**；实施席于 CMC/CEX 流低谷期执行，`InsertTicks` 失败由采样器下轮覆盖（节流语义天然容忍单轮丢帧）；禁用 `timescaledb.transaction_per_chunk` 等变体增加不确定性（单 chunk 无收益）
- 验收：`EXPLAIN (ANALYZE)` 前后对照入报审（Index Scan Backward on `ticks_key_ts_idx`，rows=1，Buffers 从 ~40k 页降至个位）；pg CPU 止血目标 <80% 稳态；`pg_stat_statements` 中 `LatestTick` mean_exec_time 由 1098ms 降至 <5ms

**索引不替代分层**：索引后闸 4 仍是「每帧→PG 往返」——池连接占用与 RTT 仍随帧率线性涨，只是不再烧 CPU。

## 5. 治本（P2 分层票——闭环前）

1. 3.1 五处切 qbus（接口形态见表）；pgstore 两变体删除
2. **冷启动**：重启后 qbus 空→闸 4 红/委任不批/展示缺——**fail-closed 如实**（D-004 禁回 PG 顶替现态）；MT5 休市例外仍由 3.2 复合钟承接（D-162 不变）
3. 看门狗：qbus 全量帧静默 >N min 已有 mt-health/cex-spread stale 告警覆盖——无新造
4. 验收：① `grep -rn "LatestTickMid\|\.LatestTick(" internal/api internal/research internal/ir` 命中仅剩 3.2 三处 ② pending 组合非空时 pg CPU <50% 且 `pg_stat_statements` 中 `LatestTick` 调用增量 ≈ 休市 miss 次数（量级 /h 而非 /s）③ 重启冷态 10s 内闸 4 全红→帧到即绿（实拍）④ D-633 伪证锚不触

## 6. 不在本案（裁掉的备选）

- **微服务拆分**：进程边界不解数据分层病——拆后 ticks 表照样被倒扫；4C/7G 单机治理成本>收益（D-633 重申）
- **PG 侧物化「最新价」表/触发器**：等于在 DB 层重造 qbus 已有的现态表，双写双源违「一事实一处」
- **池域隔离**：同病另一副药（「炸了不陪葬」）——有效但独立，不与本案捆绑；分层落地后再评是否仍需（本案把最大读面挪出 PG，池竞争源头减半）
